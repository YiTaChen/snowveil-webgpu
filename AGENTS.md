# Snowveil project instructions

- Visual quality is a release requirement. Never treat a compiling scene or a
  working feature as visually accepted without captured-frame review.
- Read `ORIGINALITY.md`, `ASSETS.md`, and `QUALITY.md` before adding code, visual
  assets, audio, or dependencies.
- Do not copy, port, translate, or closely reconstruct source code, shaders,
  scene layouts, branded names, characters, or effect choreography from any
  reference project.
- Prefer original procedural systems and self-authored assets. Record every
  external asset before committing it.
- Keep WebGPU startup failures legible and preserve a clean non-WebGPU fallback.
- Update `DECISIONS.md` when changing the rendering architecture or visual scope.
